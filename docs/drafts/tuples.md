# Кортежі

`Кортежі` - це впорядеована незмінна структура даних схожа зі списком

Порожній кортеж:

``` python

my_tuple = ()

```

Кортеж з данними:

``` python

my_tuple = (1,2,3,4,5)

```

!!! tip

    Якщо в кортежі буже один елемент, обовязково треба після елемента поставити кому

    ``` python

    my_tuples_with_1_elem = (1,)

    ```
