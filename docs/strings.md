### Len

У списках я казав що можна знайди довжина за допомогую `len()`(від англ. довжина) 

він працює на :

* str
* list
* dict

(там ще є тупли але вони вам поки не потрібні)

У `str` щоб порахувати довжину рахується кожен символ(навіть `'_'`)

``` python

my_string = 'hello world' 

print(len(my_string)) # 11

```
