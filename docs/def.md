# Фунцкії

`Функції` - це іменовані блоки коду, які виконують певне завдання

### Синтаксис

``` python

def назва():
    ...

```


### Приклад

``` python

def summa(a,b):
    return a + b

```

Пояснюю:

1.`return` - ключлве слово яке перекладається ==повернути== як не дивно повертає(ого:)) значення з функції
2.Функції мають параметри(параметри-це змінні які передаються коли створюється,  але є функції які не мають параметрів)

### Аргументи

Коли ми написали функцію нам треба подивитися що вона зробила(те що повернула)

Тоді нам треба написати тпку штуку:

``` python

print(назва_функції())

```

Це називається викликом функції

Коли ми запускаємо файл то буде виклечина функція яку ми вказали


### Функції які НЕ повертають `нічого`

Є функції які не мають `return` замість нього є `print()`

Приклад:

``` python

def print_hello():
    print('Hello')

```

І такі функції теж можна викликати, але вже не треба їх огортати в `print()`


### Фунцкія main() 


Коли в нас є багато флункції які треба викликати ніхто не пише просто в кінкі файлу, а замість цього запусують виклики в main

``` python

def f():
    ...
...

def main():
    f()
    ...

main()

```
