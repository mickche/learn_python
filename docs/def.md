# Функції

`Функції` — це іменовані блоки коду, які виконують певне завдання

## Синтаксис

```python

def назва():
    ...

```

Приклад:

``` python

def summa(a, b):
    return a + b

```

Поясню:

`return` — ключове слово, яке перекладається як «повернути». Як не дивно, повертає (ого :)) значення з функції

Функції мають параметри (параметри — це змінні, які передаються під час створення функції, але є функції, які не мають параметрів)


### Аргументи та виклики

Коли ми написали функцію, нам треба подивитися, що вона зробила (те, що повернула)

Тоді нам треба написати таку штуку:

``` python

print(назва_функції())

```

Це називається `викликом функції`

Коли ми запускаємо файл, то буде викликана функція, яку ми вказали

Якщо в нас функція має параметри то коли ми викликаємо фкнкцію ми в дужки пишемо `аргументи`

``` python

print(summa(1,2))

```

### Функції які не мають return

Є функції, які не мають return, а замість цього використовують print().


``` python

def print_hello():
    print('Hello')

```
